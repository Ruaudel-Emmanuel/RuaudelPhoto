🌟 Overview
This is a responsive, single-page portfolio website designed for Emmanuel Ruaudel, a professional documentary photographer specializing in corporate, institutional, and event reportage.

The goal of this design was to create an online presence that is not just a gallery, but a curated narrative experience—a highly aesthetic digital representation of the artist's unique visual voice. The site emphasizes elegance, readability, and maximum visual impact right from the homepage Hero section.

✨ Key Features & Design Philosophy
Visual Impact First: Utilizes an immersive hero background image with overlaying text to immediately capture attention and set a dramatic tone (The Documentary feel).
Professional Minimalism: The design adheres to a clean, editorial aesthetic using custom fonts (Playfair Display for artistic titles, Inter for readability) and muted color palettes.
Seamless User Experience (UX): Structured as a single-page application (SPA) flow, guiding the visitor through the narrative: Introduction $\rightarrow$ Philosophy $\rightarrow$ Services $\rightarrow$ Portfolio $\rightarrow$ Contact.
Responsiveness: Built with modern CSS techniques (clamp(), flexbox, and media queries) ensuring flawless display across mobile phones, tablets, and large desktop monitors.
Niche Focus: The content structure is explicitly tailored to professional clients (TPE & PME), positioning the photographer as a reliable brand asset rather than just an artist.

The core of this project is self-contained within a single index.html, making it easy to deploy and maintain. The visual assets (images) should be placed in an /assets/img folder if you expand the repository.

[project-root]/
├── index.html      # Main structure, styling, and content
├── favicon.ico     # Site icon
